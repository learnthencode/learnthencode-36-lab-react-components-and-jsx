# Lab: React Components and JSX

## Objective

Practice building React applications by creating functional components and writing JSX.

## Learning Outcomes

By completing this lab, you should be able to:

- Create and export functional React components.
- Write JSX to describe user interfaces.
- Compose components by rendering one component inside another.
- Install and use React dependencies in a project.

## Instructions

Complete the starter files until all automated tests pass.

Run the tests using:

```bash
npm install
npm test
```

Do not modify any files outside the `starter` directory.
